# R2V 光栅图转 CAD 工具 · 规格（精度优先版）

> 版本：0.1-draft
> 目标：在「可用」之上追求「可测、可比、可回归」的几何精度。
> 原则：宁可少输出，也不输出无法标注误差的东西。

---

## 0. 能力边界（硬性，必须出现在 CLI --help、GUI 首页、导出 DXF 的注释头）

- 本工具输出的是**对输入图像的几何近似**，不是对现实物体的测量还原。
- **未配准（无控制点、无比例尺）的输出，其尺寸无任何可信度**，不得用于加工、报建、算量、结算。
- 输入下限：**≥300 DPI、线条与背景局部对比度可辨、单页单图、无明显透视畸变**。低于此标准须走 `--accept-low-quality` 并写入警告。
- 明确不做：三维、曲面、填充图案/ hatch 语义识别、图块(block)语义识别、手写体、PDF 内嵌矢量还原、照片级场景。
- 所有自动结果默认视为**草稿**，人工校核是流程的一部分，不是可选项。

## 1. 精度目标与误差预算（这是本规格的核心）

### 1.1 基准换算

| 扫描分辨率 | 1 像素 ≈ |
|---|---|
| 300 DPI | 0.0847 mm |
| 400 DPI | 0.0635 mm |
| 600 DPI | 0.0423 mm |

工具必须从 TIFF/JPEG/PNG 的分辨率元数据读取 DPI；缺失时默认 300 并 **WARN**。
内部坐标统一使用 **float64，单位 = 毫米**（仅在图像读写边界做 px↔mm 换算）。
禁止在管线中途使用像素整数坐标参与几何计算。

### 1.2 端到端误差预算（配准后，300 DPI 干净线图）

| 项目 | 目标 | 硬上限 | 测量方法 |
|---|---|---|---|
| 直线段端点位置误差 | ≤1.0 px | ≤2.0 px | 与 golden 对应端点欧氏距离 |
| 线段长度相对误差 | ≤0.5% | ≤1.5% | \|L_out − L_gold\|/L_gold |
| 圆弧半径相对误差 | ≤1.0% | ≤2.5% | 拟合圆半径比对 |
| 圆心位置误差 | ≤1.5 px | ≤3.0 px | — |
| 完整圆闭合误差 | ≤1.0 px | — | 拟合残差 |
| 直线度/正交性偏差 | ≤0.3° | ≤0.8° | 与 golden 夹角（建筑图模式） |
| 曲线弦高（sagitta）过冲 | ≤0.5 mm | ≤1.0 mm | 输出曲线到 golden 的最大距离 |
| 拓扑正确率（节点连接关系） | ≥98% | ≥95% | 节点邻接表同构比对 |
| 多余短线（spurious）密度 | ≤0.5 条/cm² | ≤1.5 条/cm² | — |
| 断线率（应连未连） | ≤2% | ≤5% | 按 golden 边数计 |
| 文字定位误差 | ≤1.5 px（基线起点） | — | 与人工标注比对 |
| 文字识别准确率 | ≥90%（清晰印刷体） | — | 字符级 |

> 注：以上"px"均指**输入图像像素**，报告时必须同时换算成 mm。

### 1.3 误差来源分级归因（report.md 必须逐条填）
预处理引入 / 二值化偏移 / 骨架细化偏移 / 拟合近似 / 量化取整 / DXF 写出舍入。
其中 **DXF 写出舍入必须 ≤0.01 mm**（即写出位宽不得成为误差源）。

## 3. 数据与坐标契约（最容易错，最先写）

### 3.1 坐标约定
- 图像坐标系：原点在**左上角**，x 向右，y **向下**，单位 px。
- 世界坐标系（CAD）：原点在**左下角**，x 向右，y **向上**，单位 mm。
- 变换链：`px_img →(DPI)→ mm_img →(flip Y)→ mm_cad →(配准仿射)→ mm_world`
- 每一步必须有**逆变换**实现，用于将 CAD 层标注回叠到原图做 debug 叠加。
- 所有变换以 3×3 齐次矩阵 float64 表示，禁止分散写死 `h - y`。

### 3.2 DPI 处理
- 优先读 TIFF `XResolution/YResolution` + `ResolutionUnit`；PNG pHYs；JPEG EXIF。
- 若 X/Y 分辨率不一致 → WARN 并按 X 处理，记录 anisotropy 比值。
- 若图像被非等比缩放过（常见于扫描件）→ 在 report 中标注「各向异性畸变风险」。

### 3.3 中间产物契约
- `workdir/` 下每阶段产物以 **内容 hash** 命名，支持增量重跑（只重跑上游变更的分支）。
- 每个阶段产出 `metrics_<stage>.json`：含 `count_*`、`timing_ms`、`error_estimate`、`warning[]`。
- 全局 `manifest.json`：输入 hash、config hash、git commit、版本、起止时间、退出码。
- **可复现性**：固定随机种子、排序稳定（按坐标字典序），同一输入两次运行产出比特级一致。

## 4. 管线设计（逐阶段输入/输出/失败模式）

### S0 摄入与质检（新增，精度项目的闸门）
输入：原始图像。输出：`qc_report.json` + 通过/拒绝/降级三态。
检测项：
- DPI 存在性与合理性（<200 → 拒绝或强制降级标记）
- 有效分辨率估计（用边缘自相关估算真实锐度，识别「标称 600 DPI 实际模糊」）
- JPEG 压缩环状伪影 / 彩色半调网点（莫尔纹）检测 → 触发去网滤波
- 页面倾斜（Hough 主线角度）→ 自动旋转校正，记录角度
- 透视畸变（四边检测）→ 超过阈值则拒绝并提示「需投影校正」
- 光照不均/阴影（分块均值方差图）→ 触发自适应二值化或背景平坦化
- 折痕/污渍（大面积非图斑）→ 掩膜标记，后续不参与矢量化

### S1 预处理
- 转灰度（ITU-R BT.709 权重），彩色图先做**颜色通道分离**：每通道独立二值化后合并，避免彩色细线丢失。
- 背景平坦化：大核形态学开运算或分块多项式拟合估背景，做除法/减法归一。
- 去噪：双边/非局部均值（保留边缘），**禁止**大核高斯模糊（会位移边缘）。
- 反白自动检测：前景像素占比 < 10% 且均值 > 128 → 反转。
- 输出：归一化灰度图 + 质控标记。

### S2 二值化与边缘定位（精度关键）
- 主路径：Sauvola / Niblack 自适应（应对光照不均）+ Otsu 全局双路，选**局部对比度更一致者**（以前景像素连通域尺度稳定性为判据）。
- **子像素边缘**：在二值化轮廓上沿梯度法线做二次插值（或 Canny 亚像素化），得到亚像素轮廓；后续所有几何量由此派生。
- 线中心提取（细线优先）：距离变换脊线 / Steger 式中心线提取，用于线宽 < 3px 的图纸（地形图等高线、蓝图晒图）。
- 输出：二值图 + **亚像素轮廓链** + 逐点线宽估计（距离变换 ×2）。

### S3 骨架化与拓扑重建（最难的环节，单独验收）
- 双路径并行：形态学细化骨架 **与** 距离变换中轴，按线宽一致性选择；交叉处统一使用中轴。
- 毛刺修剪：阈值以**本地线宽的倍数**表达（默认 2.5×），不以绝对像素表达——这是跨 DPI 精度的关键。
- 节点分类：端点 / T 型 / Y 型 / 十字 / 角点，输出 `graph.json`（节点坐标、类型、邻接边 ID、入射角）。
- 断线桥接：间隙 ≤ 3×线宽 且方向延续性（入射角差 ≤ 20°）满足 → 桥接并标记 `bridged:true`；超过则保留缺口并记入报告。
- 冗余节点消除：共线连续节点（偏离线段 ≤0.5 px）合并。
- 验收：节点类型准确率 ≥95%（用合成图，节点位置已知，可精确断言）。

### S4 几何图元拟合（精度核心）
每条边独立拟合，模型竞争：`直线 / 圆弧 / 完整圆 / 贝塞尔(可选)`。
流程：
1. Douglas-Peucker 粗简化（chordal tolerance = `fitting.dp_epsilon_px` px）。
2. 分段：按曲率符号变化与残差突变切分成候选段。
3. 对每段并行拟合直线（最小二乘）与圆（**Taubin 代数初值 → 几何距离 LM 精化**）。
4. 模型选择：**残差 F 检验 + BIC 惩罚项数**，而非单一残差阈值（防止过度用圆弧拟合噪声折线）。
5. G1 连续约束：相邻弧/线在共享节点处切线角差 > 5° 时，尝试重新分段或降级为多段线。
6. 回退：残差 > `arc_residual_px` 或弧长/半径比异常 → LWPOLYLINE（bulge 或纯折线），并打标签。
7. 完整圆判定：闭合度 + 圆心到首尾距离 + 覆盖角 ≥ 330° → CIRCLE 实体。
8. 长曲线分段输出时，必须在接头处保证坐标完全一致（共享端点，禁止缝隙）。
拟合容差默认值必须以 **mm** 表达（config 中 px 仅为派生，由 DPI 反算）。

### S5 线宽恢复与分层（决定"像不像原图"）
- 线宽估计：每边取中位数本地线宽（距离变换），做鲁棒聚类（KDE/DBSCAN）得到 3–5 个主笔宽档位。
- 输出：DXF 多段线全局宽度 = 该档线宽（mm）；或在图层名编码 `_W0.35`。
- 自动分层依据（可配置优先级）：线宽档 → 走向（水平/垂直/斜）→ 颜色 → 位置（图框内外）。
- 建筑图专用：`--orthogonalize` 开关，将偏离主轴 ≤2° 的线段强制正交化（并记录被修正的角度与位移，写入 report）。
- 图框/标题栏检测：最大外接矩形 + 内侧平行线组 → 单独图层 `BORDER` / `TITLEBLOCK`。

### S6 文字分离与 OCR
- 分离判据：连通域面积、长宽比、**笔画宽度一致性**（文字笔画宽度分布窄，线条长而均匀）、与邻近骨架的距离。
- 行/字分组：按 x-height 估计做行合并，处理倾斜行（投影剖面 + 旋转校正）。
- 压线文字：文字掩膜从线骨架中**扣除**，线在此处断开并标记 `gap_by_text`，后期可选择性桥接。
- OCR：输出 TEXT/MTEXT，位置取**基线左端**（非外接矩形中心），高度由像素 x-height × DPI 反推为 mm。
- 旋转文字：保留旋转角；竖排中文单独路径。
- 明确局限：字号 < 8pt（@300DPI 约 < 8px 字高）、压线、密集注记、手写 → 成功率显著下降；提供 `--skip-text`。
- 文字层不参与几何精度验收，单独考核字符准确率。

### S7 配准与尺度
模式：
- `none`：仅像素→mm（按 DPI），输出带明显警告。
- `scale`：给定比例尺（如 1:500）或两点真实距离 → 统一缩放。
- `two-point`：两点法（平移+旋转+等比缩放，Helmert），保持形状不变形。
- `affine`：≥3 控制点，允许各向异性与剪切（适用于扫描变形）。
- `projective`：≥4 点，仅在接受了透视畸变的图上使用，并警告「角度与面积不再保真」。
输出 `transform.json`：矩阵、逐点残差、RMS、最大残差点、建议剔除点。
交互：GUI 提供控制点拾取 + 残差可视化 + 单点剔除重算。

### S8 DXF 组装
- R2018，ezdxf；单位 mm；`$INSUNITS=4`（mm）；`$LUNITS=2`。
- 实体：LINE / LWPOLYLINE(bulge) / ARC / CIRCLE / TEXT / MTEXT / POLYLINE(宽线)。
- 图层：`LINES_Wxx` / `ARCS` / `CIRCLES` / `TEXT` / `BORDER` / `DEBUG`；颜色按线宽档映射。
- 写出舍入：坐标保留 **4 位小数（0.0001 mm）**，不得成为误差源。
- 元数据：在 DXF 注释/$COMMENTS 写入工具版本、config hash、manifest id、配准 RMS、警告语。
- 自检：写出后立即回读，比对实体数、端点坐标（容差 1e-3 mm），不一致 → 报错退出。

## 5. 配置体系（config.yaml + schema）

- 所有参数有 **schema（类型、范围、单位、默认值）**，非法值启动即失败，不许静默截断。
- 三级覆盖：内置默认 < `config.yaml` < CLI 参数 < GUI 滑块。
- 关键参数必须以物理量为主、像素为辅：
  ```yaml
  fitting:
    tolerance_mm: 0.085        # 主参数（≈1px@300DPI）
    dp_epsilon_px: null        # 未设则由 tolerance_mm 与 DPI 反算
    arc_residual_factor: 1.5   # × 线宽，而非绝对像素
  skeleton:
    spur_removal_linewidths: 2.5   # 毛刺修剪 = 2.5 倍本地线宽
  bridge:
    max_gap_linewidths: 3.0
    max_angle_deg: 20
