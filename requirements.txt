# R2V 光栅图转 CAD · 运行依赖（锁定版本）
#
# 安装：
#     python -m pip install -r requirements.txt
#
# 版本锁定依据（不许凭印象改）：
#   1. 验收基线 = Linux + Python 3.10（用户决策 #4）。
#   2. 每个版本都用 scripts/verify_wheels.py 查过 PyPI 元数据：
#      cp310 + manylinux_x86_64 有 wheel；本机开发环境（Windows + cp314）也有 wheel。
#   3. 校验命令（CI 必跑）：python scripts/verify_wheels.py --check
#
# 为什么有 python_version 标记（重要，别删）：
#   实测事实——numpy / scipy / scikit-image 的**没有任何单个版本**同时提供
#   cp310-manylinux wheel 与 cp314-win wheel：
#       numpy        2.2.6  -> requires_python >=3.10；2.3.0 起 >=3.11，2.5.x 起 >=3.12
#       scipy        1.15.3 -> >=3.10；1.16.0 起 >=3.11
#       scikit-image 0.25.2 -> >=3.10；0.26.0 起 >=3.11
#   因此按解释器分流：<3.12 用验收基线组（3.10/3.11 均可用），>=3.12 用开发组。
#   **验收与回归以 <3.12 组为准**；>=3.12 组只用于本机（3.14）自测，不得用于出具精度结论。
#   若将来把验收环境升到 3.12+，删掉 <3.12 两行并重新跑 --check。
